# Public sample catalog

The public Web Player song selector is data-driven by `public/songs/index.json`.

At the documentation-restructure baseline, the published catalog contains 22 entries:

- J-POP: 4
- Anime: 4
- Game Battle: 2
- Game Field: 2
- Techno: 4
- Jazz: 2
- Chopin: 4

The catalog file is the source of truth for the exact current list. This document defines publication
rules and provenance rather than duplicating every filename.

## Original modern samples

Modern-genre samples are original demonstration material. They may use broad genre production
vocabulary but must not copy a specific artist's protected melody, lyrics, or arrangement.

## Chopin material

The public Chopin category contains complete performance transcriptions of:

- Prelude in E minor, Op. 28 No. 4
- Prelude in A major, Op. 28 No. 7
- Prelude in C minor, Op. 28 No. 20
- Waltz in A minor, B. 150

The compositions are public-domain works. The three Op. 28 preludes were cross-checked against
public-domain Mutopia Project editions; the B. 150 note/rhythm data was checked against a complete
57-measure public-domain MusicXML edition used by the project.

The `.soraoto` files are performance transcriptions. Engraving-only page-layout information is not
part of the playback DSL.
