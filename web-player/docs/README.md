# Web Player documentation

Web Player documentation is separated by responsibility.

- [`specs/`](specs/README.md): browser-reference external behavior, supported profile, publication
  contract, and explicit conformance limitations.
- [`design/`](design/README.md): internal architecture, ownership, lifecycle, fallback strategy,
  and verification design.

Portable soraotoDSL and Plugin ABI rules are **not** defined here. They are owned by
[`../../docs/specs/soraotoDSL/`](../../docs/specs/soraotoDSL/README.md).

Do not add new Markdown files directly under `web-player/docs/` except this index.
